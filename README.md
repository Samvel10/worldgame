# Բառիկ

Հայերեն բառագուշակման ամբողջական խաղ՝ React, TypeScript և Vite տեխնոլոգիաներով։

## Գործարկում

Պահանջվում է Node.js 22.12 կամ ավելի նոր տարբերակ։ Նախագիծը ստուգվել է Node.js 24.15.0-ով։

```bash
npm ci
npm run dev
```

Բացիր [տեղային խաղը](http://localhost:5173)։

Վերջնական հավաքում և տեղային դիտում՝

```bash
npm run build
npm run preview
```

Վերջնական ֆայլերը հայտնվում են `dist/` պանակում։ Դրանք կարելի է տեղադրել ստատիկ կայքերի ցանկացած սպասարկիչում։ Բառարանը և տառատեսակները տրամադրվում են տեղային ֆայլերով, արտաքին API կամ հաշիվ չի պահանջվում։ `file://`-ով բացելու փոխարեն օգտագործիր HTTP սպասարկիչ։

## Battle ռեժիմ

Realtime multiplayer ծառայությունը գործարկիր առանձին տերմինալում․

```bash
npm run battle
```

Հաճախորդը լռելյայն միանում է `ws://localhost:8787` հասցեին, իսկ տեղակայման դեպքում օգտագործիր `VITE_BATTLE_URL`։ Սենյակները աջակցում են 2–8 հյուր կամ գրանցված մասնակից և չորս ժամանակային փուլ՝ հեշտ, միջին, բարդ ու փորձագետ։ Գրանցված օգտատերերի Battle պատմությունը պահվում է `server/data/accounts.json`-ում։ Հանրային տեղակայման համար ծառայությունը պետք է աշխատի HTTPS/WSS հակադարձ պրոքսիի հետևում և հետագայում օգտագործի ընդհանուր տվյալների բազա։

Կայքը PWA է և աջակցող բրաուզերներում տեղադրվում է որպես հավելված։ Service worker-ը գրանցվում է production build-ում։

## Խաղի հնարավորությունները

- Չորս պատրաստի մակարդակ և անհատական խաղ՝ բառի երկարության, փորձերի ու բարդության ընտրությամբ։
- 433 ընտրված գաղտնի պատասխան և 65 002 ընդունվող բառ՝ տեղային բառարանում։
- 3–21 տառանոց բառեր։ «ու»-ն և «և»-ը մեկական վանդակ են։
- Կրկնվող տառերի ճիշտ գնահատում՝ նախ կանաչ, ապա մնացած տառերի հաշվարկով դեղին։
- Էկրանային հայերեն ստեղնաշար, ֆիզիկական հայկական մուտք, Enter, Backspace և տեղադրվող տեքստի ստուգում։
- Հեշտ մակարդակի մեկ ակնարկ, հաղթանակի ու պարտության պատուհաններ, նոր խաղ և կրկին խաղալ։
- Խաղերի, հաղթանակների, տոկոսների, հաղթական շարքերի և փորձերի բաշխման վիճակագրություն։
- Ապահով պահպանում `localStorage`-ում, վնասված տվյալների վերականգնում, վիճակագրության զրոյացում՝ հաստատմամբ։
- Լուսավոր ու մութ թեմաներ, ստեղնաշարով հասանելի պատուհաններ, գունային արդյունքների լրացուցիչ նշաններ, նվազեցված շարժումների աջակցություն։
- Հեռախոսի համար հարմարեցված տեսք, ներառյալ երկար բառերի նեղ, բարձր վանդակները։

Ընտրած կարգավորումները կիրառվում են «Սկսել խաղը» կամ «Նոր խաղ» կոճակով։ Անավարտ խաղը փոխարինելուց առաջ ցուցադրվում է հաստատում։ Վիճակագրությունը հաշվում է միայն ավարտված խաղերը։ Վերջին օգտագործված բառերը չեն կրկնվում, մինչև տվյալ խմբի ընտրությունը սպառվի։

## Ստուգումներ

```bash
npm run lint
npm run typecheck
npm test
npm run dictionary:check
npm run build
npx playwright install chromium
npm run test:e2e
PLAYWRIGHT_PREVIEW=1 npm run test:e2e
```

Unit թեստերը ստուգում են normalization-ը, հայկական նիշերը, բառարանի ստուգումը, կրկնվող տառերի գնահատումը, ստեղների վիճակների առաջնահերթությունը, ընտրությունն ու պատմությունը, ավարտը, վիճակագրությունը, վնասված պահոցը և բառարանի վավերացումը։

Playwright-ը ստուգում է հաղթանակը, պարտությունը, անվավեր փորձերը, ստեղնաշարերը, նոր խաղը, անհատական կարգավորումները, ակնարկը, վիճակագրության զրոյացումը, պատուհանների կենտրոնացումը, թեմայի պահպանումը և բառարանի բեռնման վերափորձը։ Այն նաև գործարկում է axe մատչելիության ստուգում երկու թեմաներում և ստուգում երկար բառերի դասավորությունը 320, 390, 650 և 768 px լայնություններով։ Հայկական ֆիզիկական ստեղնի իրադարձությունը նմանակվում է DOM KeyboardEvent-ով․ գործիքը չի փոխում համակարգի ստեղնաշարի լեզուն։

Տեսողական ստուգման պատկերները՝ `docs/screenshots/`։

## Բառարանի աղբյուրը

[Hyspell](https://github.com/martakert/hyspell)՝ CC0 1.0 արտոնագրով։ Բնօրինակից առանձնացվել են փոքրատառ հայերեն բառերը՝ առանց ածանցներով նոր բառերի ավտոմատ ստեղծման։ Գաղտնի պատասխանները ձեռքով ընտրվել են առանձին, ապա մեքենայորեն համեմատվել աղբյուրի բառացանկի հետ։ Մեթոդը, ամրագրված տարբերակը և սահմանները մանրամասն նկարագրված են [բառարանի փաստաթղթում](docs/DICTIONARY.md)։

## Սահմանները

- Բառացանկը սպառիչ չէ․ որոշ իրական ժամանակակից բառեր կամ հոլովաձևեր կարող են բացակայել։ Ընտրված բառերը հաստատված են բառարանի աղբյուրով, ոչ անկախ լեզվաբանի փորձաքննությամբ։
- Բարդությունը խաղային դասակարգում է, հիմնականում՝ ըստ երկարության։
- Տվյալները պահպանվում են տվյալ բրաուզերում և չեն համաժամացվում սարքերի միջև։ Պահոցն արգելափակված լինելու դեպքում խաղը շարունակում է աշխատել, բայց տվյալները չեն պահպանվում։
- Էջի թարմացումը սկսում է նոր բառ․ անավարտ խաղի վանդակները չեն վերականգնվում։
- 19 տառանոց ընտրված պատասխան չկա․ այդ երկարությունը չի առաջարկվում։
- Ավտոմատ բրաուզերային ստուգումները կատարվել են Chromium-ով։
